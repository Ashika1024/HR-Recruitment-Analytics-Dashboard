# 📊 HR Recruitment Analytics Dashboard – Power BI

## 📌 Project Overview

The **HR Recruitment Analytics Dashboard** is an interactive Power BI project that analyzes recruitment data to provide valuable insights into hiring performance, candidate quality, recruitment trends, and HR decision-making.

The dashboard helps organizations understand their recruitment process through KPI tracking, data visualization, and business-focused analytics.

---

## 🛠️ Tools & Technologies

* **Power BI**
* **DAX (Data Analysis Expressions)**
* **Power Query**
* **Data Cleaning & Transformation**
* **Data Visualization**
